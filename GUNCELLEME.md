# MEVCUT UYGULAMAYI v3'E GÜNCELLEME

1. GitHub > akcali-mekanik repository'sine gir.
2. Eski şu dosyaları yenileriyle değiştir:
   - index.html
   - styles.css
   - app.js
   - sw.js
   - manifest.webmanifest
   - apple-touch-icon.png
   - icon-192.png
   - icon-512.png
3. backend.gs değişmediği için Apps Script tarafını değiştirmek zorunda değilsin.
4. Commit changes yap.
5. iPhone'da internet açıkken Akçalı Mekanik uygulamasını kapatıp yeniden aç.
6. Sağ üstte `v3.0` görünmeli.
7. Görünmezse:
   - Safari'de GitHub Pages uygulama adresini bir kez aç ve yenile.
   - Sonra ana ekran uygulamasını tekrar aç.
8. Ayarlar > LİSTELERİ GÜNCELLE yap.
9. Yeni Hata ekranında Blok/Kat/Hata Türü/Taşeron/Formen açılır listelerini kontrol et.

Google Sheet ve mevcut bulut URL'si aynen çalışmaya devam eder.
